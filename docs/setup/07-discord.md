# 07 Discord:Webhook の作成

**ゴール**: 文字起こしの完了・失敗を受け取るための Webhook URL(`DISCORD_WEBHOOK_URL`)を作る。
**前提**: [02-accounts.md](02-accounts.md) で Discord と通知用サーバーを用意済み。
**仕組み**: [../architecture/05-callback-and-notification.md](../architecture/05-callback-and-notification.md)

Webhook は「この URL に送ると、このチャンネルにメッセージが出る」という通り道です。**URL を知っている人は誰でも投稿できる**ので、秘密にします。

公式: <https://support.discord.com/hc/ja/articles/228383668>

## ステップ 1: 通知用チャンネルを選ぶ

**やること**

1. Discord を開き、通知を受け取りたい**自分用サーバー**を左端のアイコンから選ぶ。
2. 左のチャンネル一覧から、通知用のチャンネル(例: `#general`、または新しく作った `#whisper`)を決める。
   - 新しく作る場合は、チャンネル欄の **+**(チャンネルを作成)→ 名前を入力 → **チャンネルを作成** をクリックする。

✅ **正常な場合**: 選んだチャンネルの画面が開く。

## ステップ 2: Webhook を作る

**やること**

1. チャンネル名の右にある **⚙ チャンネルの編集**(歯車)アイコンをクリックする。
2. 左メニューの **連携サービス**(Integrations)をクリックする。
3. **ウェブフック**(Webhooks)をクリックし、**新しいウェブフック**(New Webhook)ボタンをクリックする。
4. 作られたウェブフックをクリックして展開し、名前を `whisper` などに変更する(任意)。
5. **ウェブフックURLをコピー**(Copy Webhook URL)ボタンをクリックする。
6. **変更を保存**(Save Changes)をクリックする。

✅ **正常な場合**: クリップボードに、次の形の URL がコピーされる。

```
https://discord.com/api/webhooks/<数字>/<ここに値>
```

📝 **控える値**: `DISCORD_WEBHOOK_URL` → [05-cloudflare.md](05-cloudflare.md) のシークレット登録で使う。

❌ **異常な場合**

| 症状 | 原因 | 対処 |
|---|---|---|
| **連携サービス** が表示されない | サーバーの管理権限が無い | 自分で作成したサーバーで行う |
| ボタンが **Webhooks** と英語表記 | 言語設定 | 英語表記のまま同じ手順で進める |

## ステップ 3: 届くか試す

次のコマンドで、テストメッセージを送ります。`<URL>` は控えた Webhook URL に置き換えます。

```sh
curl -s -o /dev/null -w "%{http_code}\n" -X POST "<URL>" -H "Content-Type: application/json" -d '{"content":"テスト通知です"}'
```

✅ **正常な場合**: `204` と表示され、チャンネルに「テスト通知です」が出る。

❌ **異常な場合**

| 表示 | 原因 | 対処 |
|---|---|---|
| `404` | URL が間違っている/ウェブフックが削除された | URL を再コピーまたは作り直す |
| `401` | URL の末尾のトークンが欠けている | 全体をコピーし直す |
| `429` | 短時間に送りすぎ | 少し待つ |
| `000` | ネットワークエラー | 接続を確認 |

⚠️ テストの URL をシェルの履歴に残したくない場合は、実行後に `history -d` で消すか、履歴を残さない設定を使ってください。URL を人に見せないでください。

## 通知の内容

実際のアプリが送る文面(本文は送られません):

```
✅ 文字起こしが完了しました
ファイル: 第3回講義.mp3
https://<アプリのホスト>/jobs/<ジョブID>
```

```
❌ 文字起こしに失敗しました
ファイル: 第3回講義.mp3
理由: timeout
https://<アプリのホスト>/jobs/<ジョブID>
```
