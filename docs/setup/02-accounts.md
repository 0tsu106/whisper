# 02 アカウントの作成

**ゴール**: Cloudflare、Modal、Hugging Face、Discord のアカウントを用意する。すでにお持ちのものは飛ばしてください。
**前提**: メールアドレスと、ブラウザ。

> ⚠️ 画面表記は変わることがあります。ボタン名が違う場合は、近い意味のボタンを選んでください。
> 無料枠・カード登録の要否は、2026-11-03 時点の調査で**情報源によって食い違い**がありました。**登録画面の表示を正としてください。**

## A. Cloudflare

公式: <https://dash.cloudflare.com/sign-up>

**やること**

1. ブラウザで <https://dash.cloudflare.com/sign-up> を開く。
2. **Email** 欄にメールアドレス、**Password** 欄にパスワードを入力する。
3. **Sign up**(サインアップ)ボタンをクリックする。
4. 届いた確認メールのリンクをクリックして、メールアドレスを認証する。
5. ダッシュボードが開いたら、画面左のメニューに **Workers & Pages** や **R2 Object Storage** などが並んでいることを確認する。

✅ **正常な場合**: Cloudflare のダッシュボード(左にメニュー、右に「Account Home」)が表示される。

```
┌─ 左メニュー ──────┬─ メイン ──────────────┐
│ Account Home      │  ドメインを追加…      │
│ Workers & Pages   │                       │
│ R2 Object Storage │                       │
└───────────────────┴───────────────────────┘
```

❌ **異常な場合**

| 症状 | 原因 | 対処 |
|---|---|---|
| 確認メールが届かない | 迷惑メール/入力ミス | 迷惑メールフォルダを確認。ダッシュボードの確認メール再送を使う |
| ログイン後すぐ認証画面に戻る | メール未認証 | メールのリンクをクリックしてから再ログイン |

📝 **控える値**: 後で「アカウント ID」が必要です。[05-cloudflare.md](05-cloudflare.md) で取得方法を説明します。

> 💳 R2(ファイル置き場)を有効にするとき、**支払い方法の登録を求められる場合があります**(無料枠内なら課金されません)。[05-cloudflare.md](05-cloudflare.md) のステップで案内します。
> 参考: <https://developers.cloudflare.com/r2/pricing/>

## B. Modal

公式: <https://modal.com>

**やること**

1. <https://modal.com> を開き、右上の **Sign up**(または **Get started**)をクリックする。
2. **Continue with GitHub** / **Google** など、使えるログイン方法を選ぶ。
3. 画面の案内に従って、ワークスペース名(英数字とハイフン)を決める。
4. ダッシュボードが開くことを確認する。

✅ **正常な場合**: Modal のダッシュボードが開く。左に **Apps** や **Settings** などのメニューがある。

❌ **異常な場合**

| 症状 | 対処 |
|---|---|
| カード登録を求められる | **GPU 関数(このアプリの T4)の利用にはカード登録が必須です**([04](04-modal.md) のデプロイ時に `Please add a payment method to use T4 GPU functions` と出ます)。無料クレジットの範囲で使う想定で、登録後に **Budgets** で Spend limit を小さく設定してください(Starter プランに毎月の無料クレジットがあります。料金ページ: <https://modal.com/pricing>) |
| ワークスペース名が使えない | 別の名前にする。**この名前が後でエンドポイント URL に入ります** |

📝 **控える値**: ワークスペース名(エンドポイント URL に含まれる)。

## C. Hugging Face

公式: <https://huggingface.co/join>

**やること**

1. <https://huggingface.co/join> を開く。
2. **Email Address** と **Password** を入力して **Next** をクリックする。
3. ユーザー名などを入力して登録を完了する。
4. 届いた確認メールのリンクをクリックして認証する。

✅ **正常な場合**: ログイン状態で Hugging Face のトップが表示される。右上にアイコンが出る。

❌ **異常な場合**: 確認メールを未認証のままだとトークンの作成やモデルの利用同意ができないことがあります。メールのリンクを押してください。

## D. Discord

公式: <https://discord.com/register>

**やること**

1. <https://discord.com/register> を開き、必要事項を入力して **Continue** をクリックする。
2. すでにアカウントがあれば、ログインするだけでよい。
3. 通知を受け取る**自分専用のサーバー**を作っておく(次のファイルで使う)。
   1. 左端の **+**(サーバーを追加)をクリックする。
   2. **Create My Own**(自分用に作成)→ **For me and my friends**(自分と友達用)を選ぶ。
   3. サーバー名を入力して **Create** をクリックする。

✅ **正常な場合**: 左端にサーバーのアイコンが追加され、`#general` チャンネルが見える。

❌ **異常な場合**: ロボット確認(CAPTCHA)が繰り返される → ブラウザの拡張機能を一時的に無効にして再試行。

## チェックリスト
